# Taller de Carpintería "Madera y Arte" - Proyecto OOP Java

## 📋 Descripción del Proyecto

Este proyecto simula la gestión de un taller de carpintería y ebanistería llamado **“Madera y Arte”**, ubicado en Bogotá, Localidad de Fontibón.  
El sistema gestiona clientes, muebles, pedidos y carpinteros, aplicando los principios de **Programación Orientada a Objetos (POO)**: clases, objetos, encapsulación, constructores, métodos y relaciones entre objetos.

**Especialidad del taller:** Muebles a medida, reparaciones y restauración de muebles antiguos.  
**Cantidad de carpinteros:** 6  
**Producción mensual aproximada:** 20 muebles
